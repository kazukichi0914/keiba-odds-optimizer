# keiba-odds-optimizer
⚬ netkeibaのオッズAPIと競馬ラボの予想印をリアルタイムで取得し、指定した総予算内で最適な金額配分を自動算出するChrome拡張機能です。 ⚬ ワイドを必須条件とし、トリガミを完全に回避しつつ的中率と回収率のバランスを取るダッチング計算を実装しています。 ⚬ ブラウザから完全に分離されたコア計算ロジック（core/）を採用しており、実データを用いた安定したテスト駆動開発（TDD）を行っています。 ⚬ 締切直前の慌ただしい時間帯でも、計算ミスや感覚に頼った配分をなくし、論理的な馬券購入をサポートします。
